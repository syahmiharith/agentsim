# Support

Agentsim is an early, solo-maintained open-source project. Support is best-effort.

## Where to Ask

- Use GitHub issues for reproducible bugs, scoped feature requests, documentation fixes, workflow improvements, and eval cases.
- Use GitHub discussions for broad ideas, questions, roadmap discussion, and product direction.
- Use pull requests for focused changes that are ready for review.
- Use GitHub Security Advisories for vulnerabilities, leaked secrets, private data exposure, prompt-injection issues with security impact, or sensitive generated artifact risks.

## Support Expectations

Maintainers may prioritize issues that improve the current software-freelance CLI workflow, artifact quality, traceability, reviews, approvals, and final package handoff.

Broad platform requests, hosted-service requests, generic agent chat features, and production deployment support may be deferred until the narrow vertical slice is stronger.

## Sensitive Data

Do not post API keys, credentials, private client data, private generated artifacts, or sensitive prompt/output traces in public support requests.
