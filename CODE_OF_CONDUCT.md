# Code of Conduct

Agentsim follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project maintainers are expected to keep discussions practical, respectful, and focused on improving the artifact-first software-freelance workflow.

## Reporting

Report unacceptable behavior privately to the project maintainers.

Do not include private client data, credentials, API keys, or sensitive generated artifacts in public issues or discussions.
