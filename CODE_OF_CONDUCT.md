# Code of Conduct

Agentsim follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) for project spaces.

## Expected Behavior

Contributors and maintainers are expected to:

- communicate respectfully and directly
- focus criticism on ideas, code, artifacts, and project fit
- assume ordinary mistakes before assuming bad intent
- keep discussions practical and relevant to Agentsim's artifact-first software-freelance workflow
- respect contributor time by keeping issues and pull requests clear and scoped
- avoid posting secrets, private client data, private generated artifacts, or sensitive prompt/output traces

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, insults, or sustained disruption
- discriminatory language or conduct
- sexualized language or unwelcome sexual attention
- publishing another person's private information without permission
- knowingly posting credentials, API keys, private client material, or sensitive generated outputs
- repeatedly derailing project discussions after maintainers ask for focus

## Scope

This code applies in project spaces, including GitHub issues, pull requests, discussions, code review, documentation, and community channels created for Agentsim.

## Enforcement

Maintainers are responsible for clarifying expectations and responding to conduct issues. Enforcement may include editing or removing comments, closing issues or pull requests, temporary restrictions, or permanent bans from project spaces.

Maintainers should apply this policy consistently and avoid conflicts of interest when possible.

## Reporting

Report conduct concerns privately to the project maintainer. If no private contact is listed, open a minimal public issue asking for a private reporting channel and do not include sensitive details.

For security-sensitive reports, leaked secrets, private client data, or prompt/output traces that could expose sensitive information, use GitHub Security Advisories instead of a public issue.
