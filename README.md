# Agentsim

Agentsim is an artifact-first AI organization layer for solo software freelancers.

This MVP proves one narrow workflow: a high-level client software request becomes a scoped, reviewed, runnable delivery package.

## Demo

```bash
pnpm install
pnpm demo "Build an inventory request system for a flower company"
```

The command writes:

```text
outputs/{runId}/final-package/
+-- client/
+-- planning/
+-- technical/
+-- app/
+-- review/
+-- trace/
```

Use mock mode explicitly for deterministic no-key runs:

```bash
pnpm demo "Build an inventory request system for a flower company" --mock
```

Use live mode when `.env` contains an OpenAI-compatible key:

```bash
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4.1-mini
pnpm demo "Build an inventory request system for a flower company" --live
```

If no live key is configured and `--live` is not passed, Agentsim falls back to mock mode.

## MVP Spine

- `Agent`
- `TaskRun`
- `Artifact`
- `Workspace`
- `Decision`
- `Approval`
- `Event`

The current driver is local filesystem only. Docker, dashboards, SaaS BYOK, complex memory, and marketplace features are intentionally out of scope for v0.
